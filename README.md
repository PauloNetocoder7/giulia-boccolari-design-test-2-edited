# Dott.ssa Giulia Boccolari – Psicologa

Sito professionale della Dott.ssa Giulia Boccolari, Psicologa a Modena e online.

## Sviluppo locale

**Prerequisiti:** Node.js 18+

1. Installa le dipendenze:
   `npm install`
2. Avvia il server di sviluppo:
   `npm run dev`
3. Per creare la build di produzione:
   `npm run build`
